# 深研档案馆 dossier

丢进一个**你还没有答案的问题**,本机 Tangu 多轮检索后在你自己的笔记库里落成一份 `.dossier.md` 档案:
**每条断言配引注、每条引注 URL 真的被机器请求过、同一课题可续研并与上一版逐条 diff。**

它不是「又一个 AI 面板」。差异化只有三件事:**结构化档案文件 + 机器验证过的引注 + 可重跑的增量续研**。

## 为什么做它

- 深研 agent 的引注**表面漂亮、事实层不可靠**:2026-05 的 *Cited but Not Verified*(14 个模型)测出链接有效率 >94%、相关性 >80%,**事实正确率只有 39–77%**;工具调用从 2 次增到 150 次时事实正确率再掉约 42%。<https://arxiv.org/abs/2605.06635>
- 引注里的 URL 本身也在骗人:arXiv 2604.03173(DRBench 53,090 + ExpertQA 168,021 条 URL)测出 **3–13% 的引用 URL 是幻觉**(互联网档案馆没有任何快照)、5–18% 整体不可达;把「HEAD/GET + Wayback」这道判级接上后,不可达 URL 降低 6–79 倍到 <1%。本插件的四级判据就是照它做的。<https://arxiv.org/abs/2604.03173>
- 引用造假在加速:The Lancet 审计约 250 万篇论文、1.256 亿条参考文献,捏造引用出现率 2023 年每 2,828 篇 1 篇 → 2026 年初每 277 篇。
- 「核对 AI 产出」已是知识工作者自评第一位的人类技能(Microsoft 2026 Work Trend Index,20,000 名在职 AI 使用者,50%)。
- 现有产品把这件事锁在别人家界面里:NotebookLM 2026-08 仍**不能跨本检索、不能整份导出**,消费版没有公开 API;按次计量的 deep research 也很贵(Plus 每月只有 10 次)。

## 怎么用

1. **开一个课题** — 命令面板「深研档案馆:打开」进课题台(或切到「档案馆」Space),写下你还没有答案的问题,点「开研」。
   检索台实时显示步骤条(提交 / 检索 / 起草 / 体检 / 落盘)与模型输出;**关掉视图它照跑**,跑完自动落盘。
2. **看档案** — 文件树里点 `.dossier.md` 用插件自己的阅读视图打开:结论摘要、断言(每条带引注编号与支持度徽章)、
   证据源(判据徽章 / 原文引文)、未决问题、检索记录。右上角 `</>` 切到源码全文直接改,保存走同一条写队列。
3. **续研** — 课题列表每行的「续研」再跑一轮。**旧断言编号保持不变**,新断言拿新号;旧版本整份存进 `.history/`。
   跑完顶部给出「自上次以来」:新增 / 变化 / 移除的断言与新增证据源。**这一轮没带来新内容就不产生新版本**(不制造噪音版本)。
4. **体检引注** — 落盘后默认自动跑一次(设置里可关)。也可以随时点某个课题的「体检」,或跑命令
   「深研档案馆:体检当前笔记的链接」把当前笔记里所有 URL 抽出来跑同一套体检。
5. **找回档案** — 课题台底部的「找回档案」是**修复路径**:让 Agent 只跑一条 `ls` 列出工作文件夹下的 `*.dossier.md`,
   插件逐个读回重建索引。正常流程不依赖它;手工拷进来的档案、或索引损坏后用它收编。

## 引注体检的四级判据

模型只回**原始探测数据**(`curl -sIL` 的状态码与最终 URL、退出码,以及互联网档案馆的 `available` 查询结果);
**判定只出自插件里的一个纯函数**,模型输出里出现任何 verdict / level / 结论字段一律丢弃。

| 判据 | 含义 | 触发条件 |
|---|---|---|
| **可达** `LIVE` | 这个地址刚刚请求得到 | 最终状态码 2xx(3xx 链落到 2xx 也算) |
| **已失效** `DEAD` | 请求不到,但档案馆存过它 —— 链接腐烂,不是编造 | 404/410 或 DNS 解析失败,**且** Wayback 有快照 |
| **疑似虚构链接** `LIKELY_HALLUCINATED` | 请求不到,而且档案馆从未见过它 | 404/410 或 DNS 解析失败,**且** Wayback 明确回「没有」 |
| **未判定** `UNKNOWN` | 证据不足,不下判断 | 401/403/405/429 访问控制、5xx、超时、TLS 错误、**Wayback 自己出错或没答复**、本次没探到这条 |

三条纪律:
- **保守优先**:证据不足一律「未判定」。Wayback 自己 error 时**绝不**判编造 —— 解析失败 ≠ 缺席的正证据。
- **可达性优先**:200 但档案馆没快照(新页面),判「可达」,不因为没被存档就怀疑它是编的。
- **体检失败绝不降级已存判据**:保留上次结论 + 上次时间,只把本次没拿到数据的标「未体检」。

这套判据在 check.mjs 里被 **30 条已知真假向量**(10 真 / 10 已腐烂 / 10 编造,其中 4 条是必须判「未判定」的陷阱)钉死。

## 数据存哪

| 东西 | 路径 | 说明 |
|---|---|---|
| 档案 | `<工作文件夹>/<课题>.dossier.md` | **唯一真源**,纯 Markdown,可直接当笔记读、被全库搜索与双链引用 |
| 版本历史 | `<工作文件夹>/.history/<课题>/v0001.dossier.md` | 整份快照,零填充四位,diff 用同一个解析器跑快照与当前文件 |
| 课题索引 | `<工作文件夹>/.dossier-index.json` | **纯派生,只负责发现**;每个字段都能从它指向的档案重算 |
| 单篇体检报告 | `<工作文件夹>/体检/<日期>-<笔记名>.md` | 点「另存报告」才生成 |
| 解析失败的原始输出 | `<工作文件夹>/.history/<课题>/failed-<时间戳>.txt` | 点「另存原始输出」才生成 |

工作文件夹 = 宿主标准约定(插件详情页的「工作文件夹」设置,默认 = 插件名)。
写序是 **① 快照 → ② 档案 → ③ 索引**:②③ 之间崩了只是索引落后一版,下次打开该档案时按文件重算并自愈。
索引 JSON 损坏会先备份成 `.dossier-index.json.bak` 再重置,**绝不静默清空**,档案文件一根汗毛都不动。
全部读-改-写走**串行写队列**,并发的续研 / 体检 / 源码保存互斥排队。

## 范围说明(明确不做什么)

- **不做「跟笔记聊天」** —— 那是宿主 chat 的活。这里的产物是文件,不是对话。
- **不承诺 audio overview / 播客化**(宿主有语音识别,没有语音合成)。
- **不判断证据「真假」** —— 语义层只输出「已找到支持证据 / 未找到支持证据」两态,**刻意没有「假」这个值**。
  「疑似虚构链接」只描述 **URL 可达性**,不评价内容真伪。
- **不做 soft-404 判定**:返回 200 但内容已经换掉的页面仍判「可达」。
- **不改写你正在编辑的笔记**:`dossier-check-note` 只出并排报告,永不回写活动页。
- **不删除文件**:「移出列表」只动索引,要删档案请去文件树。
- **不做定时自动续研**:App 关了没有守护进程,不做假承诺。
- **URL 抽取有一处已知边界**:链接后面**紧跟**汉字、中间没有任何分隔符时(`见 https://zh.wikipedia.org/wiki/贝叶斯定理这条`),
  那几个字会被算进链接。中文维基 / 百科的路径本身就是汉字,插件宁可多带也不截断 —— 截断的后果是去请求站点首页,
  拿回一个假的「可达」,比误报更隐蔽。链接后面加个空格或标点即可;带括号的路径(`…_(statistics)`)按括号配平自动处理。
- **不做付费墙 / 登录墙内的内容**,不代登录、不绕付费。
- **不带随包 Agent**:两条 run 都用默认助手 + host 模式,纪律全写在英文指令段里。

## 旧宿主兼容

07-18 之后的 ctx 面一律可选链,缺席时优雅降级、**setup 绝不抛错**:

- 没有 `registerFileType`(或它返回 `false`,后缀被内置占走)→ **整体退让**:跳过右键新建与斜杠项,两个视图与四条命令照常注册。
- 没有 `registerStatusItem` / `notify` / `activity` / `achievements` → 藏起来 / 回退 `ctx.app.notify` / 不埋点。
- 没有 `ctx.app.workFolder` → 回退默认文件夹名;没有 `ctx.app.prompt` → 命令走视图入口,「移出列表」跳过二次确认。
- 没有引擎(web / 台架 / `window.tangu` 缺席)→ 课题台**只读可用**,「开研」降级为提示。

## 双语说明

界面全量中英双语:一份 `MSG` 词表(两侧键集合相等,check.mjs 断言),取串走 `ctx.getLocale()`,
订 `ctx.subscribeLocale` —— **切语言时视图不重挂也就地变英文**,正在跑的检索、已展开的体检面板、
编辑中的源码都不会被打断。日期按语言本地化(`zh-CN` / `en-US`)。

**用户数据与路径不随语言变**:课题问题原文、断言与正文、证据源标题 / URL / 引文、slug、工作文件夹名、
localStorage 键一律原样。档案文件里的章节标题与标签由 `dossier_lang`(建档时定死,此后只由你手改)决定,
判据值恒为 ASCII —— **切 UI 语言不会重写任何一份档案文件,输出逐字节相同**(check 有断言)。

**已知缺口**:命令面板 / 斜杠菜单 / 设置页 / 视图标签页 / 成就的标题是宿主的**单字符串**贡献点,
宿主不做运行时重解析 —— 注册时取的是**当时**的语言,**切换语言后这几处要重启应用才跟上**。
这是宿主侧的已知缺口(codex 2026-08-14 评审已记录);插件**不做**「语言变了就重注册 / 自己 teardown 重来」的规避
(那会打断正在跑的检索与已打开的视图)。插件视图内部不受影响。

## 自检

```bash
node check.mjs
```

宿主同款 `new Function('ctx', src)(mockCtx)` + DOM 垫片 + 冻钟 + 内存 vault。覆盖:贡献点齐全、
四级判据 30 条向量、`normalizeUrl` / `parseProbeJson` / 档案解析序列化往返(含未知 frontmatter 键、未知 H2 小节、
围栏里的 `###`、块标记行、空档案、EOF 无换行)、id 分配与源判重、版本 diff 与幂等指纹、XSS、
数据契约往返(写→读→再写 + 历史快照 + 索引损坏备份 + 读失败零写入)、双语词表与切语言重渲、
两个旧宿主 ctx(缺席版 / 退让版)、disposer、源码扫描。

真机 UIUX 门禁(深浅两档对比度 + 中英切换,真浏览器):

```bash
cd ../../Forsion-Genesis/desktop
node scripts/plugin-view.e2e.cjs ../../Forsion-Instrumentality-Project/forsion-plugin-dossier \
  --expect-views desk,run --expect-commands dossier-open,dossier-new,dossier-continue,dossier-check-note
```
